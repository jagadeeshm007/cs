# 📄 Resume & Applications

## Resume rules
- One page, clean, ATS-friendly (no tables or graphics); a PDF named `FirstName_LastName_SWE.pdf`
- Bullets: **Action verb + what + how (tech) + measurable impact**
  - ❌ "Worked on a workflow engine using Go"
  - ✅ "Built a durable AI workflow engine in Go (Postgres leases + fencing tokens, Kafka outbox) that completed 5,000 chaos-tested runs with zero duplicate side effects; cut LLM cost 40% via model routing and semantic caching"
- Skills section grouped: Languages · Backend · Data · Cloud/DevOps · AI
- Projects: **Orbit: AI Workflow & Agent Platform** (link + 3–4 strong bullets with numbers)
- Links: GitHub (pinned repos, clean READMEs), LinkedIn, blog
