# 🚀 Emerging Tech & Trends (2026): awareness → selective depth

| Trend | What to know | Depth |
|---|---|---|
| **Agentic AI + MCP + A2A** | Tools, protocols, safety, durable agents | 🔴 Deep (Phase 5) |
| **Context engineering** | Managing what goes into the model's context: retrieval, memory, compaction | 🔴 Deep |
| **AI-assisted development** | Using coding agents productively; reviewing AI code; spec-driven development | 🔴 Daily practice |
| **LLM gateways & FinOps for AI** | Routing, quotas, caching, cost per request | 🟠 Medium |
| **Durable execution** (Temporal, Restate) | Reliable long-running workflows | 🟠 Medium |
| **Platform engineering / IDPs** | Backstage, golden paths, self-service infra | 🟡 Awareness |
| **Kubernetes Gateway API** | Replaces Ingress | 🟠 Medium |
| **eBPF** | Cilium, observability, security without sidecars | 🟡 Awareness |
| **Sidecar-less mesh** (Istio ambient) | Cheaper mTLS | 🟡 Awareness |
| **Java: virtual threads, structured concurrency, Valhalla, Leyden, GraalVM** | Modern JVM performance | 🟠 Medium |
| **Go: generics, iterators, PGO** | Modern Go | 🟠 Medium |
| **Lakehouse** (Iceberg) + real-time OLAP (ClickHouse) | Data architecture | 🟡 Awareness |
| **Vector search inside general DBs** (pgvector, OpenSearch) | You often don't need a separate vector DB | 🟠 Medium |
| **WebAssembly on the server** (WASI, Envoy/proxy filters) | Plugins, edge compute | 🟡 Awareness |
| **Supply chain security** (SLSA, Sigstore, SBOM) | Increasingly expected | 🟠 Medium |
| **Passkeys / WebAuthn** | Passwordless auth | 🟡 Awareness |
| **Post-quantum TLS** | Hybrid key exchange rollout | 🟡 Awareness |
| **Local-first & CRDTs** | Offline-capable collaborative apps | 🟡 Awareness |
| **Edge compute** (Cloudflare Workers etc.) | Low-latency global apps | 🟡 Awareness |
| **OpenTelemetry everywhere** (incl. GenAI conventions) | Standard observability | 🔴 Deep |

> [!tip] Rule for trends
> Learn the **problem each trend solves** and one concrete example. Go deep only if it's on the critical path for your target roles.
